# HazırPlan — Family Emergency Plan App (TR-first, then PE)

Hermes: this is the standalone HazırPlan venture (NOT Mumo, NOT homeschool — strict separation).
Read `specs/mvp-spec.md` before building anything. Load the `hazirplan-venture` skill if available.

## Product in one line
Free, offline-first family emergency plan builder for Turkey (ReadyPlan-inspired, TR-localized): guided wizard → plan of steps + linked sheets → shared to every family phone via Aile Kodu (no accounts) → kept alive via tatbikat reminders + Hazırlık Skoru.

## Non-negotiables (violations = rework)
1. **Offline-first**: no feature requires connectivity at moment of use. Flight-mode e2e walkthrough is a release blocker.
2. **Free + no paywall in MVP.** Generous free tier (3 plans, unlimited Aile Kodu sharing).
3. **No AI features** — deterministic wizard + template assembly + deterministic Hazırlık Skoru.
4. **No accounts in MVP** — sharing = Aile Kodu (encrypted export/QR). Local storage only (IndexedDB/Dexie). No backend, no KVKK burden in MVP.
5. **No earthquake alerts** — AFAD/Kandilli territory; complement, never compete.
6. **Turkish-first copy** in app UI; plain civil-defense language (AFAD-compatible), no military jargon; docs/comments in English.
7. Never invent social-proof numbers (user is data-rigorous).

## Stack (decided)
SvelteKit static export PWA · Dexie (IndexedDB) · Paraglide i18n (tr first, es-pe pack later) · Leaflet + cached tiles · Vitest + Playwright. Content packs as JSON (`src/content/tr.json`).

## Conventions
- Wizard saves MUST be confirmed visibly + covered by an e2e test asserting the plan appears in the list (ReadyPlan's bug, our blocker).
- `scorePlan(plan, sheets, drillLog)` stays a pure function, 100% unit coverage.
- Commit per task, conventional commits (feat:/fix:/chore:).
- Deploy target: GitHub Pages (user's pattern; pages.dev blocked in TR, Netlify credit out — confirm host before deploying).
- ReadyPlan research account credentials live ONLY in the browser vault — never in files, chat, or this repo.
